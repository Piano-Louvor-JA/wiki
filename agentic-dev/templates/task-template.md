# TASK template

Use one task at a time for an implementer or coding agent.

```markdown
## Task: <phase-task — title>

Files: <exact paths>
Approach: <steps constrained by SPEC and PLAN>
Test: <RED then GREEN command>
Commit: <conventional commit message>

Rules:
- Follow repository AGENTS.md.
- Do not touch unrelated files.
- Do not mix pre-existing formatting changes.
- Stop and report an undecided blocked decision.
```

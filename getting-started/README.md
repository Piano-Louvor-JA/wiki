# Getting Started

Setup de cada projeto. Escolha o teu destino:

- [app (desktop Electron)](app.md) — Electron + Vue 3 + Vuetify + Pinia + Vite
- [api (REST)](api.md) — Hono + Zod OpenAPI + SQLite
- [apk (mobile Flutter)](apk.md) — Flutter + Dart, offline-first
- [web (PWA)](web.md) — Vue 3 + Vite + PWA + Vuetify 4

## Pré-requisitos comuns

- Node.js 22+ (LTS)
- npm 10+
- Docker (para API local com SQLite)
- Flutter SDK 3.24+ (para apk)

## Próximos passos

1. Clone o repo do projeto desejado
2. Siga o getting-started específico do repo
3. Leia `AGENTS.md` para convenções e regras "NUNCA faça"
4. Use `methodology/README.md` para navegar na metodologia (core + domain skills)

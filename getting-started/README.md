# Getting started

Choose the repository you will change, then read its local README and `AGENTS.md` before installation.

- [app — desktop Electron](app.md)
- [api — shared contracts and services](api.md)
- [apk — Flutter mobile](apk.md)
- [web — browser PWA](web.md)

Use the documented package manager and environment example supplied by each repository. Do not commit local environment files.

## Escopo

PIANO / LouvorJA é uma família de produtos de software que apoia fluxos de culto e
apresentação. Cada repositório tem uma responsabilidade distinta; use o README e as
orientações de contribuição de cada um como a entrada local autoritativa.

## Fluxo de contribuição

1. Selecione uma issue com resultado claro.
2. Leia as instruções do repositório e os testes relevantes.
3. Crie uma branch focada.
4. Implemente a menor mudança segura.
5. Rode as verificações documentadas no repositório.
6. Abra um pull request para revisão.

## Antes de compartilhar material

Remova credenciais, URLs privadas, caminhos operacionais, dados de clientes e
capturas de tela que revelem informação privada.

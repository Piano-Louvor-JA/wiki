## Escopo

Este repositório publica apenas orientação de onboarding segura e reutilizável.
Decisões internas, planos ativos, ADRs, automação de board, endereços de
infraestrutura, configuração de deploy e credenciais permanecem privados.

Se uma página aqui puder expor informação sensível, remova o conteúdo
imediatamente e notifique os mantenedores por um canal privado.

## Fonte da verdade

A documentação privada do projeto é a fonte da verdade para decisões internas.
Peça acesso a um mantenedor quando necessário.

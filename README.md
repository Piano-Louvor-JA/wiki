## Scope

This repository publishes safe, reusable onboarding guidance only. Internal
decisions, active plans, ADRs, board automation, infrastructure addresses,
credentials and operational metrics stay private.

If a page here may expose sensitive information, remove it immediately and
notify maintainers through a private channel.

## Source of truth

Internal project documentation is the source of truth for internal decisions.
Ask a maintainer for access when needed.

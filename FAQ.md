# FAQ

## Is this the full internal documentation?

No. This site is a deliberately limited public onboarding surface.

## Where are current project decisions and delivery plans?

Private project documentation is the source of truth. Ask a maintainer for access when needed.

## Can I publish an internal note here?

No, unless a maintainer has converted it into safe public guidance and reviewed it for sensitive content.

## What must never be added?

Credentials, tokens, private paths, infrastructure addresses, deployment configuration, personal data, internal specifications, real plans, roadmaps, board automation, project records and operational metrics.

## How do I propose a change?

Open a focused pull request with validation evidence and a short explanation of the public benefit.

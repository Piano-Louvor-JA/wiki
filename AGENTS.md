# Public agent guide

Use this repository as public onboarding material only.

## Rules

- Read `GETTING_STARTED.md`, `ARCHITECTURE.md` and `CONTRIBUTING.md` before changing code.
- Keep changes small, testable and documented.
- Do not add credentials, access tokens, personal data, server addresses, private repository paths or production configuration.
- Do not publish internal specifications, plans, ADRs, roadmaps, project-board automation or delivery metrics here.
- Treat private project documentation as the source of truth for internal decisions.

When unsure whether information is public, omit it and request review.

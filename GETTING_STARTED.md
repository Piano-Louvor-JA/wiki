# Getting started

## Scope

PIANO / LouvorJA is a family of software products that supports worship and presentation workflows. Repositories have distinct responsibilities; use each repository's README and contribution guidance as the authoritative local entry point.

## Contribution flow

1. Select an issue with a clear outcome.
2. Read repository instructions and relevant tests.
3. Create a focused branch.
4. Implement the smallest safe change.
5. Run the repository's documented checks.
6. Open a pull request for review.

## Before sharing material

Remove credentials, private URLs, operational paths, customer data and screenshots that reveal private information.

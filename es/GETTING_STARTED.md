## Alcance

PIANO / LouvorJA es una familia de productos de software que apoya los flujos de culto y
presentación. Cada repositorio tiene una responsabilidad distinta; usa el README y las
guías de contribución de cada uno como punto de entrada local y autorizada.

## Flujo de contribución

1. Selecciona un issue con un resultado claro.
2. Lee las instrucciones del repositorio y las pruebas relevantes.
3. Crea una rama enfocada.
4. Implementa el cambio más pequeño y seguro.
5. Ejecuta las verificaciones documentadas en el repositorio.
6. Abre un pull request para revisión.

## Antes de compartir material

Elimina credenciales, URLs privadas, rutas operativas, datos de clientes y capturas de
pantalla que revelen información privada.
